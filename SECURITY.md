# Security Policy

## Supported Versions

At any given time, only the latest tagged version of the software (see
[Tags](https://github.com/akeeba/release-system/tags) on the GitHub repo) is
supported for the purpose of security issues.

Furthermore, it is only supported on the following environment:

- The latest published stable version of Joomla compatible with the software.
- A supported PHP version compatible with the software.

## Reporting a Vulnerability

Report security issues on GitHub using [the security page](https://github.com/akeeba/release-system/security/advisories)
– click on "Report a Vulnerability".

We usually respond within two business days, but it may take as long as three weeks due
to travel, illness, etc.

We will contact you with our review of your vulnerability report. Should we need more
information we will ask you about it. We will coordinate with you about disclosure.
We typically request a month since successful triage to develop a patch and make a
new release. We have no-release blockers during Christmas, Easter, the first four weeks
of August, and bank holidays; these do not count for the disclosure window. We may ask
for an extension due to extenuating circumstances. This is a single-person company; we
do not have tens of staff working around the clock and a simple cold or offline
obligation may necessitate a small wait. That said, we generally aim for a patched
release and coordinated disclosure within ten days or less.

Please do not feel rushed if we propose a short timeline for a coordinated disclosure.
You are humans, too. You have your own life, obligations, and responsibilities. If you
ask us to extend the disclosure we will be happy to oblige.
