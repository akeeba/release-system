# ARS Translation Glossary — French (France) / Français (France)

This glossary defines the approved French (France) translations for ARS-specific terminology.
Translators must follow these translations consistently throughout all `fr-FR` language files.

| English | French (France) | Notes |
|---|---|---|
| Akeeba Release System | Akeeba Release System | Proper noun / product name — do not translate |
| BleedingEdge | BleedingEdge | Technical term for the developer-release category type — do not translate |
| Bleeding Edge | Bleeding Edge | Two-word variant of the above — do not translate |
| Category | Catégorie | Context: a software release category (e.g. normal or BleedingEdge) |
| Release | Version | Context: a versioned software release (e.g. 7.4.0). Avoid « sortie » or « publication » in this domain |
| Item | Élément | Context: a downloadable file or link within a release |
| Download ID | Identifiant de téléchargement | Authentication token used to authorise file downloads; abbreviation « ID de téléchargement » acceptable in space-constrained UI labels |
| Update Stream | Flux de mise à jour | Context: an XML/INI feed consumed by the Joomla updater |
| Update stream | Flux de mise à jour | Lower-case variant — same translation |
| Environment | Environnement | Context: a software compatibility environment (e.g. PHP 8.1, Joomla 4) |
| Auto-description | Description automatique | Context: an automatically generated item description rule |
| Automatic description | Description automatique | Full-form variant of the above |
| Control Panel | Panneau de contrôle | Admin dashboard / component home screen |
| Download Logs | Journaux de téléchargement | Log records of file downloads |
| Stable | Stable (Stable) | Release maturity level; English word kept in parentheses for clarity — the French adjective is identical |
| Release Candidate | Version candidate (RC) | Release maturity level; RC abbreviation may be retained in labels and feeds |
| Beta | Bêta | Release maturity level; accented form standard in French; « Beta » acceptable as fallback in technical contexts |
| Alpha | Alpha | Release maturity level; kept as Alpha across languages |
| Repository | Référentiel | Context: the entire ARS download repository |
| Maturity | Niveau de maturité | Context: the maturity level of a release (Alpha / Bêta / RC / Stable) |
| Webservices | Webservices | Technical term — do not translate |
| Dashboard | Tableau de bord | Admin component home screen (short label) |
| Official Releases | Publications officielles | Category type label shown to frontend visitors |
| Developer Releases | Publications pour développeurs | Frontend label for BleedingEdge category type |
| Available versions | Versions disponibles | Frontend heading listing release versions |
| Latest releases | Dernières versions | Frontend / module heading |
| Download now | Télécharger maintenant | Call-to-action button label on item view |
| Compatibility | Compatibilité | Field label listing environments an item supports |
| Security severity | Gravité de sécurité | Per-release field indicating how severe the security issue fixed by this release is (`COM_ARS_RELEASES_FIELD_SECURITY`). "Gravité" is the standard French term for CVE/vulnerability severity. Feminine noun |
| Security release | Version de sécurité | A release flagged as fixing a security issue (used in the field description and the badge label « Sécurité : %s ») |
| Critical (severity) | Critique | Highest security severity level. Agrees with "gravité" |
| High (severity) | Élevée | Security severity level. Feminine to agree with "gravité" |
| Medium (severity) | Moyenne | Security severity level. Feminine to agree with "gravité" |
| Low (severity) | Faible | Security severity level. Agrees with "gravité" |
| None (severity) | Aucune | Security severity level meaning the release has no associated security fix. Feminine to agree with "gravité" |
