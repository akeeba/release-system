# Glossário ARS — Português (Portugal)

Glossário de terminologia específica do Akeeba Release System (ARS) para tradução para Português de Portugal (pt-PT).

As entradas marcadas como **não traduzir** são nomes próprios, nomes de produto, ou termos técnicos que devem permanecer em inglês na tradução.

| English | Portuguese (Portugal) | Notes |
|---|---|---|
| Akeeba Release System | Akeeba Release System | Não traduzir — nome do produto (nome próprio). |
| BleedingEdge | BleedingEdge | Não traduzir — nome técnico de categoria de versões de desenvolvimento. Usar sempre na forma composta sem espaço. |
| Bleeding Edge | Bleeding Edge | Não traduzir — variante com espaço do mesmo termo técnico. |
| Category | Categoria | Contexto: categoria de lançamentos de software no repositório ARS. |
| Release | Versão | Contexto: uma versão numerada de software lançada publicamente. Evitar "lançamento" para não confundir com o acto de publicar. |
| Item | Ficheiro | Contexto: um ficheiro transferível ou ligação dentro de uma versão. Alternativa: "item" (neutro e amplamente aceite). |
| Download ID | ID de Transferência | Contexto: token de autenticação necessário para transferir ficheiros protegidos. Também aceitável: "ID de Download" se o público-alvo estiver familiarizado com o termo inglês. |
| Update Stream | Canal de Actualizações | Contexto: feed XML/INI utilizado pelo actualizador do Joomla para detectar novas versões. Alternativa: "Fluxo de Actualizações". |
| Update stream | Canal de actualizações | Variante em minúsculas — aplicar a mesma tradução. |
| Environment | Ambiente | Contexto: ambiente de software como PHP 8.1, Joomla 4, etc. |
| Auto-description | Descrição automática | Contexto: descrição gerada automaticamente para um ficheiro ou versão. |
| Automatic description | Descrição automática | Forma extensa equivalente a Auto-description. |
| Control Panel | Painel de Controlo | Contexto: painel de administração principal do componente ARS. |
| Download Logs | Registos de Transferências | Contexto: histórico/registo de transferências de ficheiros. Alternativa: "Logs de Transferências" (menos formal). |
| Stable | Estável (Stable) | Nível de maturidade de versão. Manter o termo inglês entre parênteses para facilitar reconhecimento. |
| Release Candidate | Candidato a Versão Final (RC) | Nível de maturidade de versão. Manter a abreviatura RC entre parênteses pois é amplamente reconhecida. |
| Beta | Beta | Manter em inglês — o termo é universalmente reconhecido e utilizado em Português. |
| Alpha | Alpha | Manter em inglês — o termo é universalmente reconhecido e utilizado em Português. |
| Repository | Repositório | Contexto: o repositório de transferências completo gerido pelo ARS. |
| Maturity | Maturidade | Contexto: nível de maturidade de uma versão (Alpha, Beta, RC, Stable). |
| Webservices | Webservices | Não traduzir — termo técnico referente à API REST/JSON:API do ARS. |
| Security severity | Gravidade de segurança | Campo por versão que indica a gravidade da falha de segurança corrigida por essa versão (`COM_ARS_RELEASES_FIELD_SECURITY`). "Gravidade" é o termo padrão em português para a gravidade de uma CVE/vulnerabilidade. |
| Security release | Versão de segurança | Uma versão assinalada como correcção de uma falha de segurança (usado na descrição do campo e na etiqueta "Segurança: %s"). |
| Critical (severity) | Crítica | Nível de gravidade de segurança mais elevado. Concorda em género com "gravidade" (f.). |
| High (severity) | Alta | Nível de gravidade de segurança. Concorda em género com "gravidade" (f.). |
| Medium (severity) | Média | Nível de gravidade de segurança. Concorda em género com "gravidade" (f.). |
| Low (severity) | Baixa | Nível de gravidade de segurança. Concorda em género com "gravidade" (f.). |
| None (severity) | Nenhuma | Nível de gravidade de segurança que indica que a versão não tem correcção de segurança associada. Concorda em género com "gravidade" (f.). |
